# Blender 美术与动作规范 · v2 手绘纸面 × 像素冒险

状态：重新规划，尚未实现或渲染。参考审计见 style-reference.md。本期仍全部使用 Blender，不引入 Remotion 外壳，不改猫咪母版。

## 视觉取舍

电脑外仍是冷蓝深夜像素房间；电脑内改为奶油纸上的手绘剪辑工作台。像素猫与游戏关卡保留像素边缘，Claude、纸签、手臂与 UI 使用轻微不规整的墨线。这样借用参考项目的手绘舞台和动作语言，同时保留用户明确要求的像素主角与马里奥式冒险。不是把猫重画成参考机器人的角色。

色板：纸面 #f6f3e9，墨线 #302d27，Claude/当前动作 #c96f58，成功 #7ebdb3，节拍 #f2cf65；猫毛色、金眼睛和天蓝工牌服从共享母版，不强行套色板。深夜房间沿用原冷蓝与暖灯。纸面纹理固定种子、低对比，不让字和猫一起抖。

## 布局与字体

1920×1080、16:9 主版。总览时左抽屉 x=80–380，游戏窗 x=420–1840、y=120–700，时间轴 y=760–910；对白 y=950–1020。操作发生在哪里，相机就温和移向哪里；任务条与非当前面板退浅，不能一直以总览小字讲故事。关键手部近景中猫至少保留一个反应镜头。

UI 与便笺拟用完整霞鹜文楷，首次使用前获取完整字体并保留 OFL；参考仓库的子集可能缺本片汉字，不能直接当通用中文字体。命令用可读等宽字体；对白用清楚的中文黑体，不逐字弹跳。字体此轮仅选型，没有下载或打包。1080p UI 约 32–40px，便笺短标题 46–60px，对白 48–56px；按手机缩小预览复核。文字与手绘层高分辨率合成，只有像素世界使用低分辨率最近邻放大。不要给全片统一马赛克。

竖版后续独立重排，不裁掉左边目标和下边轨道。

## 动作语法

1. 眼神/身体预备 → 手接触 → 拖动或按压 → 道具状态改变 → 角色反应。禁止 UI 在手没碰到前自动完成。
2. Claude 手臂是可弯的曲线，手端绑定抓取点；素材在抓住后随手运动，松开后才吸附。抓猫的选框，不抓脖子或工牌。
3. 动作主要落点参考音乐网格，预备通常 3–5 帧、接触停 2–3 帧、落位回弹 4–8 帧，可按表演微调；不是每个音符都闪一下。具体动作段见 shots.json.actionBeats。
4. 重点镜头先给问题，再看操作，再看结果，留半拍到两拍反应。猫瞪 Claude、试踩桥、提前宣布完工是三处小笑点，不靠大段文案。
5. 相机只为看清操作移动，约 1.0–1.3 倍的缓推/平移，动作前到位；关键对白停稳。手绘轮廓静态轻错位，不随机抖镜头。
6. 过场由同一个道具接力：想法便笺→选框→屏幕纸面；Git 分支→时间轴；拍点→踏板；文件→显示器→交付便笺。禁止每镜都飞入一张新卡片。
7. 粒子预算克制：金币翻贴纸、错误碎三片、完成少量纸屑；不堆星芒、霓虹和全屏故障。

## Blender 实现规划（尚未开发）

- 正交/弱透视 2.5D 分层，纸面与 UI 用原生曲线、薄片、文字；细描边用曲线或 Grease Pencil，具体方案先做三镜测试再锁定。
- Set_Room、Paper_Editor、Pixel_Game、Character_Tomcat、Character_Claude、Typography、FX 分集合；字符与工牌独立节点。
- Claude_Hand_Target 驱动手臂曲线端点；Held_Item 在抓取区间使用父级/约束，释放时烘焙世界变换，保证无跳变。
- Editor_State 驱动片段宽度、后续片段起点、桥的缺口及任务状态；s110 不能仅播放两个不相关的缩放动画。
- 由统一的全局帧号与 shots.json 范围计算状态，单独渲染 s110 首帧也应继承素材已齐的状态；不能依赖前一镜真的运行过。
- 像素猫拆头、躯干、爪、尾巴、工牌，建立跑跳/眨眼/困倦/惊讶姿势；母版身份不变，工牌始终自然可见。
- 镜头段内 actionBeats 是导演数据，目前 build_scenes.py 不会自动解释它；必须实现动画后才算完成。
- 保留 v1 的 .blend、PNG、MP4、音效与 receipt；v2 输出另命名，不能覆盖旧证据。

## 声音与字幕

继续使用用户指定的马里奥地面曲本地参考，不复制参考项目 soundtrack.m4a。200 BPM 是自动分析候选，当前 76.8 秒为预演网格，不是锁定成片。四个对白镜头的原文字不变（开头两镜连成一句），仍待真实配音、自然度审听与对齐。

现有跳跃/拾取/确认音可作为原始库复用，但 67 个 v1 触发点和旧混音不能冒充 v2 对齐音轨。新版增加揭贴纸、铅笔画线、键帽和短折纸需求；具体先选/合成再审听。对白处压 BGM 约 6–9dB，动作密集处减少提示音。泡泡字、场内标签、对白三层互不重复。

## 验收

- 先制作 s040 穿屏、s070 手臂拖贴纸、s110 修剪补桥三个样片：检验混合风格、抓取约束、真实因果。
- 静音也能看懂谁做了什么；先有操作再有反馈，猫有表情反应。
- 工牌只含蚂蚁头，无文字，不能暗示任职或官方合作；无意间露出，不强迫特写。
- 字体齐全、画面缩小仍可读；像素边缘不因缩放变糊。
- 听审卡点和语音，逐镜 QC 后才更新新的渲染回执。编码成功不等于验收。
- 公开发布前另行核实音乐、角色、商标使用范围；公开仓库不是素材授权证明。
