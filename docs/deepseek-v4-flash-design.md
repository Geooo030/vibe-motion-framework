# 热点君｜DeepSeek V4 Flash 0731（原创解说样片）

## 制作边界

参考片：[差评前沿部《DeepSeek 的梁性循环，让同行文锋丧胆了》](https://www.bilibili.com/video/BV1abuA6pES2/)，约 4:04。此前播放器观察到的六个时间点和视觉语法见 [reference-analysis.md](reference-analysis.md)。本次浏览器连接失败，且 B 站公开播放器接口没有返回字幕；因此下面是**基于同一话题和可核实资料撰写的 60 秒原创脚本**，不是原片台词或逐帧复刻。

事实依据：[DeepSeek-V4-Flash-0731 官方模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731)，以及 [DeepSeek V4 官方介绍](https://deepseek.com/en/news/v4-preview/)。模型卡中的榜单由 DeepSeek 发布；代码 Agent 公共基准使用 DeepSeek Harness minimal mode、`max` effort、`temperature=1.0`、`top_p=0.95`。不要把这些数值表述成独立实测或通用任务成功率。

## 视觉系统

- 9:16 / 720×1280 / 30 fps；全片 60 秒。深石墨色背景有缓慢漂移的代码/网格纹理，热点君原创 Logo 与栏目名固定在上方。
- 中央大证据窗（约 x=40–680、y=190–980）承担数据、资料、机制图解，字幕在窗底独立一行；底部固定主题句与双段进度线。镜头之间保留至少一条青色状态线作连续接力。
- 字体采用本机 `Noto Sans SC`（正文、字幕）和 `Bahnschrift`（数字、技术标签），不依赖原视频字体文件。青色 `#72F2E0` 标示证据/数据，青柠 `#D7F06A` 标示结论/关注，白色为正文。
- 每句旁白只配一个主动作；数字、比较条、连线、聚焦框由代码逐帧驱动。不要使用原片截图、Logo、声音或音乐。
