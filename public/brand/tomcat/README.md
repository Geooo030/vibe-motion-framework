## 固定特征

灰紫色虎斑毛、宽脸大头与短胖身体、深色额头纹、额头中央白色纹路连接白色口鼻、白色胸腹和爪子；金色眼睛、略带得意的眉眼、粉色鼻子和耳内、微张嘴带粉色舌头；带条纹的尾巴向画面右侧弯曲。保持阶梯状像素轮廓，避免换成写实、光滑矢量或 3D 风格。

## 后续视频复用规则

1. 每次制作封面、角色动作或表情，先查看这张母版，然后将它作为实际参考图传入图像生成工具；不能只靠文字重新生成一只相似的猫。
2. 可以改变动作、表情、视角和当期道具；保持脸型、体型比例、毛色分区、眼睛颜色、耳朵及额纹一致。新视角需要对照母版人工验收，不能保证单张图自动获得稳定动画。
3. 本母版两手无道具，方便增加手柄、键盘、指示棒。天蓝色挂绳与工牌是固定配饰：卡面只保留一个像素化蚂蚁集团蚂蚁头 Logo，不出现任何文字、猫咪头像、工号或二维码。需要动作时生成独立透明底版本，不覆盖母版。
4. 后续单期衍生图放 `episodes/<id>/assets/characters/`，登记母版路径、版本、SHA-256 和生成提示词。跨期共享母版仅在本公共目录保留一份。
5. Remotion 可通过 `staticFile('brand/tomcat/tomcat-pixel-master-v3-ant-logo.png')` 引用；叠加时使用透明通道，不要把黑色预览底当作背景。缩放优先整数倍或配合 `imageRendering: 'pixelated'`。
6. 后续调整创建新版本并记录切换；不覆盖历史文件，旧视频仍可复现。
7. 每个包含汤姆猫的镜头，都要在镜头内自然露出工牌；通过转身、操作键盘、抬爪等正常动作露出，不刻意定格、特写或放大 Logo。工牌跟随身体与重力轻微摆动，不能悬浮、穿模或僵硬贴屏。特写也应合理带到挂绳与工牌，分镜写明露出时机。
8. 逐镜人工验收身份一致、工牌可见、无文字且透视正确。这是制作约定，不是已经实现的自动检测。当前只更新母版和本期封面，没有重渲染旧视频。
9. 标志是按用户要求使用的第三方商标卡通配饰，不表示真实任职或官方背书，参考来源见 references/README.md。
